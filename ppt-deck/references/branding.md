# 标志与图标系统（可选）

用户觉得默认装饰图形太通用、想要项目专属标志时做。用 **logo-design skill**（`~/.claude/skills/logo-design`）的 Design 模式。

## 流程
1. **准备**：从 `svg_output/` 统计实际色值，作为标志配色（最多 3 色）；写设计简报，包括一句话概念、品牌形容词转成视觉线索、颜色语义（比如“橙色 = 被识别的异常”）、禁区（行业俗套）。
2. **3 个方向真正不同的方案**（图形标志 / 抽象符号 / 字母组合）：每个方案有完整版（封面用）和极简版（角标用），两者同源。用 `svg_audit.py` 审计，并做 16/32px、单色、反白测试。
3. **放进 PPT 预览**：把方案合成进真实封面和一张内容页，让用户看实际效果（只生成预览文件，不改正式页面）。⛔ 等用户选方案。
4. **完善选定方案**：要**适配 PPT 背景主题**（用户反馈：不能突兀）：
   - 深底版：结构用白色加低透明度（0.13–0.75），只有语义强调色是实色；
   - 白底角标：用柔和的辅助色，不用最重的主色，分量和原来的小装饰相当；
   - 背景纹理：以标志为圆心的同心大圆弧 + 稀疏节点（白色，透明度 0.03–0.07），替换位置无关的装饰圆。
5. **导出全套**：深底版、白底版、角标版、单色深 / 白（镂空要做成真正的洞）、背景纹理、组合版（文字用 fontTools 转曲）、PNG 512/1024/2048、`test-sheet.html`、`README.md`。
6. **替换进 PPT**（按修订规则）：先列替换清单；用 `scripts/embed_logo.py` 把标志坐标换算到页面里，作为矢量路径写入，不作为图片插入；只改图形，不动文字。改前备份，出替换前后对比图。⛔ 等用户确认。

## 技术要点
- 单色版的镂空：重叠图形用奇偶规则挖洞会出错。要从几何上避免重叠（比如内环在扇区处断开），保持精确圆弧；不要用折线逼近（锚点会暴增）。
- 没有 Chrome 以外的渲染器时，logo-design 的 `render_png.py` 会用 Chrome 无头模式。
- 组合版文字转曲：`fontTools` + 系统字体（如 `msyhbd.ttc`），正式商用前确认字体授权。
- 封面标志尺寸受标题宽度限制，不要让标志压到文字；放不下时宁可小一点，不擅自改版式。
