# 设计规则

所有场景通用的视觉底线，大部分来自用户的实际修改意见（见 `feedback-log.md`）。场景或模板有自己的风格时，在不违反这里底线的前提下服从场景。

## 1. 字号与字体（1280×720 画布，1px = 0.75pt）

| 角色 | SVG 字号 | 约合 |
|---|---|---|
| 封面标题 | 50–64px | 38–48pt |
| 页面标题 | 40px 粗体 | 30pt |
| 正文 | 26–28px | 20–21pt |
| 最小正文 / 标签 / 图表刻度 | 24px | **18pt（底线）** |
| 页码、脚注（唯一例外；出处脚注默认不放） | 18px | 13.5pt |

- 中文默认微软雅黑（Windows PowerPoint 原生可用）；用户或模板指定字体时，确认目标电脑装了它。
- 一页最多 4 种字号；同一角色全套统一。

## 2. 配色
- 主色 1 个（结构、标题、色带）+ 强调色 1 个（只表示“重点 / 异常 / 关键数字”这一种含义）+ 灰阶。
- 状态色同时配文字标签，不只靠颜色区分；负面状态用温和措辞（“少于预期”），不用刺眼的红色标签。
- 背景和文字对比度 ≥ 4.5:1；深色背景上的结构线用白色加低透明度。

## 3. 质感（用户反馈：纯色平涂显得廉价）
- **页面背景**：白色到浅色的竖向渐变（比如 `#FFFFFF → #EAF0F7`），写在背景矩形上，会导出成原生背景。
- **卡片**：白色卡片 + 轻阴影（`feDropShadow dy=4 stdDeviation=10 opacity=0.12`，颜色用主色）；一页最多 3–4 个浮起元素，其余平放。
- **柱子 / 色带**：同色系纵向渐变（浅 → 深）；强调色的柱子用强调色渐变。
- **标题下分隔线**：强调色 → 主色 → 透明的渐变细线（高 3px）。
- **页眉角标**：项目标志的极简版（或和封面图案同源的小图形），放在右上角，分量要轻。

## 4. 封面与封底（用户反馈：不能单调）
- 深色斜向渐变背景 + 大号半透明圆或光晕，营造空间层次；
- 一个和主题相关的图形（项目标志、关系网、数据图案等），放在侧边，约占画面宽度的 25–40%，不能压到标题；
- 标签用描边胶囊样式（场景标签可省略），团队 / 作者信息放进半透明面板，信息从简（用户删掉了封面日期），底部可以加一条渐变细线；
- 封底和封面用同一套视觉语言；有项目标志时，用标志加同心纹理替换无关的装饰。
- 克制：发光、渐变只用在一两个焦点上，不堆砌。

## 5. 图片与截图
- **截图不能有截断感**（半个饼图、被切掉的表格）：选内容完整的帧或区域。
- 截图放在带阴影的白色卡片里（留 12–14px 内边距），不直接贴在背景上。
- 截图缩放后文字小于约 10px（投影看不清）时，改用原始数据**原生重画**。
- 网络毛线团图、看不清的热力图不用；没有意义的图（比如把 ID 当数值画的柱状图）不用。
- 用户自己的图片优先；AI 图、网络图注明来源，事实类页面不用。

## 6. 图表
- 柱状图从 0 开始；目标线用灰色虚线并标注“申报目标 0.75”这类文字。
- 直接在柱子旁标数值，能不用图例就不用。
- 坐标用引擎的计算器算，不凭眼估。
- 简单图表画成原生形状（可编辑、投影清晰）；需要在 PowerPoint 里改数据时导出原生图表。

## 7. 版面
- 安全区：左右 64px，内容区约 y 170–640，页脚 y 660–700。
- 区块之间对齐、留白一致；并列的卡片同尺寸同样式。
- 流程、层级关系用箭头 / 原生形状表达，不只是并排卡片。
